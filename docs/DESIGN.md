# Paper & Pine 视觉主题

整站采用纸白背景、墨色文字和松绿主色，强调易查找、易阅读和轻量操作。

- 颜色与语义变量统一维护于 `src/app/globals.css`。主色 `#2d6250`，背景 `#f8f9f6`，正文 `#242b27`。
- 首页、分类页、工具页共用 `ToolIcon` 中的 Lucide 图标映射。分类辅色只用于低饱和度的图标底色。
- 品牌标记由 `Brand` 组件、SVG favicon 和 Open Graph 图片保持一致。
- 桌面首页采用分类侧栏与三列工具卡片；中等屏幕使用两列；手机上分类切换为按钮，窄屏改为单列。
- 主按钮统一实色，次按钮用浅底或描边。原有 `gradient` 按钮变体保留接口，外观与主按钮一致。
- 保留搜索、收藏、独立页面、服务器渲染说明、SEO 元数据与结构化数据。搜索支持 Ctrl/Cmd + K。
- 提供清晰的键盘焦点状态，并遵从 `prefers-reduced-motion`。
- 站内链接共用 `NavigationLink`，点击后使用 Next.js 的真实 pending 状态显示反馈和页面顶部进度条；工具脚本未就绪时显示 `ToolLoading` 骨架。关闭默认预加载的工具链接在悬停或聚焦时恢复预加载。

调整后需检查首页、分类页及文本、JSON、图片等不同工具的工作区，并在 320、390、768 和 1440 像素视口检查布局。

导航反馈还应在延迟页面响应及工具脚本的条件下检查：点击后提示立即出现，工具就绪后自动消失，连续切换以最后一次选择为准，返回和键盘导航不残留加载状态。
