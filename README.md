# 100-tools — 免费在线工具合集

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

无需注册，打开即用。提供颜色、图片、音频、文本、开发等各类实用在线工具。

## 工具列表（58 个）

当前共有 **58 个独立工具入口**。已将重复的 JSON 压缩/美化入口替换为 JSON 结构对比，新增文本整理工作台；去重、排序等操作集中在工作台内，不拆分计数。

每个工具都有独立页面，首页提供搜索、分类、收藏和快捷入口，工具代码按需加载。完整建设方向和后续候选见 [100 工具建设计划](ROADMAP.md)。

以下清单按 `src/data/tools.ts` 整理；已接入不代表全部旧工具均完成全面功能验收。

## 本地运行

需要 Node.js **24.22.1 或更新的 24.x 安全版本**，项目通过 `.nvmrc` 固定当前基线。使用 nvm 时先运行 `nvm install && nvm use`。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 访问。

## 开发与验证

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
npm run audit:production
```

`npm test` 使用 Node.js 原生 TypeScript 支持，需要 Node.js 24.22.1+（24.x），覆盖 JSON 结构对比、文本处理、工具注册和旧收藏迁移。全仓 lint 目前仍有旧工具的历史问题，详见 [验收记录](ROADMAP.md#本轮验收)。

工具元数据位于 `src/data/tools.ts`，组件通过 `src/components/ToolRenderer.tsx` 按需加载，独立页面由 `src/app/[...toolPath]/page.tsx` 统一生成。新增工具需要同步注册元数据和组件，并更新文档。旧 `/#工具ID` 分享链接会自动转到独立页面。

## 界面语言

支持简体中文和英文，分别使用 `/zh` 和 `/en` 路径。首次访问无语言前缀的旧链接时，根据浏览器 `Accept-Language` 选择支持的语言；没有匹配项时使用英文。浏览器提供繁体中文时，显示简体中文界面。

页头可以手动切换语言，并保留当前工具、查询参数和锚点。手动选择写入 localStorage 和一年有效、访问时续期的 Cookie，此后优先于浏览器语言；自动选择不会保存成固定偏好。收藏在两种语言间共用。工具界面、说明、页面元数据、结构化数据和 sitemap 均对应中英文版本；用户输入和生成的数据保持原样。

翻译位于 `src/lib/i18n/en.json`，语言检测与链接处理位于 `src/lib/i18n/locale.ts`，旧链接重定向由 `src/proxy.ts` 处理。新增文案时同步补齐英文翻译。

## SEO 配置

正式域名默认为 `https://tools.hboot.fun`，支持通过 `SITE_URL` 覆盖；正式站点设置 `SITE_INDEXABLE=true`，预览站点设为 `false`。支持独立页面元数据、canonical、分享图片、分类聚合页、服务端使用说明、结构化数据、robots 和 sitemap。修改配置后需要重新构建。

部署变量、Docker 构建参数和 `npm run check:seo` 的使用方法见 [SEO 配置与验收](docs/SEO.md)。

## Docker 部署

```bash
docker-compose up -d
```

构建与运行镜像均固定为 `node:24.22.1-alpine`。GitHub Actions 构建时拉取基础镜像，并在镜像构建阶段执行生产依赖高危审计。应用监听 `127.0.0.1:3000`，建议通过反向代理暴露到公网。

安全升级与开发工具剩余告警见 [安全升级记录](docs/SECURITY.md)。
